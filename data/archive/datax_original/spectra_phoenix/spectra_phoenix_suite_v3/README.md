# Spectra Phoenix

Spectra Phoenix is a starter suite for GNN-based intrusion recovery and self-healing.
This v3 bundle includes integrated RL + GNN demos, CI scaffolding, and stub dataset for immediate runs.

Quickstart:
- create a virtualenv, install requirements.txt
- run `python hetero_gnn_demo.py` to train the hetero GNN on synthetic data
- run `python rl_remediation_env_integrated.py` to train the integrated RL using GNN embeddings
- run `pytest` to run basic tests
